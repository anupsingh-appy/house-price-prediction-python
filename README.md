# House Price Prediction using Python

## Project Overview
This project performs House Price Prediction using Linear Regression in Python.

The analysis focuses on predicting housing prices based on multiple housing-related features and evaluating model performance using regression techniques.

---

## Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

---

## Dataset Information
The dataset contains housing-related variables such as:
- Crime Rate
- Number of Rooms
- Tax Rate
- Student-Teacher Ratio
- House Prices

The target variable is house price prediction.

---

## Steps Performed
1. Data Loading & Cleaning
2. Correlation Analysis
3. Feature Selection
4. Train-Test Split
5. Linear Regression Model Training
6. Price Prediction
7. Model Evaluation using R² Score and MSE
8. Visualization of Actual vs Predicted Prices

---

## Visualizations Created
- Correlation Heatmap
- Actual vs Predicted Price Scatter Plot

---

## Key Insights
- Regression analysis identified strong relationships between housing features and prices.
- The model successfully predicted house prices with reasonable accuracy.
- Features such as rooms and location-related variables significantly influenced pricing.
